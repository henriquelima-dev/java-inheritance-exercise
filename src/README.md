# Java Inheritance Exercise

This project was developed as a **study exercise** to practice basic concepts of Object-Oriented Programming (OOP) in Java.

## Purpose

The main goal of this exercise was to practice **inheritance** and understand how classes can share attributes and methods through a parent class.

## Concepts Practiced

* Classes and objects
* Encapsulation
* Private attributes
* Constructors
* Getters
* Inheritance with `extends`
* The `super` keyword
* Method overriding with `@Override`

## Structure

The exercise contains the following classes:

* `Funcionario` — parent class containing the common employee information.
* `Gerente` — child class that inherits from `Funcionario` and adds the employee's department.
* `Desenvolvedor` — child class that inherits from `Funcionario` and adds the programming language.
* `TesteFuncionarios` — class used to create the objects and test the implemented methods.

## Note

This is a simple project created **for study and practice purposes**. It was not designed to be a complete or production-ready system.

It is part of my ongoing learning process in Java and Object-Oriented Programming.
